# CRM автошколы Центр Обучения Вождению

Веб CRM для сотрудников и курсантов автошколы. В репозитории реализован только первый этап из `razbienie-na-etapy.docx`.

## Реализовано в первом этапе

- Авторизация по логину или email, защищённая PHP сессия и выход из системы.
- Шесть ролей: администратор, преподаватель, мастер производственного обучения, заместитель генерального директора, директор и курсант.
- Директор и заместитель генерального директора управляют учётными записями всех ролей. Администратор управляет только курсантами и просматривает список сотрудников без права изменений. Преподаватель, мастер и курсант не имеют доступа к управлению учётными записями.
- Списки курсантов и сотрудников находятся на отдельных страницах. На главной показаны отдельные числа активных курсантов и сотрудников.
- Для курсанта можно указать срок обучения от 1 до 120 месяцев. По истечении срока доступ автоматически блокируется; продление срока и разблокировка выполняются отдельно.
- Директор и заместитель могут сбрасывать пароль любому пользователю, администратор — только курсанту. После сброса пользователь обязан создать постоянный пароль.
- Персональные чаты курсантов с сотрудниками и инструкторами, непрочитанные сообщения и периодическое обновление диалога.
- Адаптивный интерфейс для компьютера, планшета и телефона.
- Сворачиваемое боковое меню, современные модальные окна и ненавязчивые анимации.
- Миграции базы данных и CLI-команда создания первого директора.

Модули следующих этапов — лента событий, предупреждения, лиды, договоры, задачи, группы, финансы, вождение, теория и документы — намеренно не добавлены.

## Требования

- PHP 8.1 или новее с расширениями `pdo_mysql`, `mbstring`, `json`, `curl`.
- MySQL 5.7 или новее.
- Apache с `mod_rewrite` либо другой веб-сервер, который направляет несуществующие пути в `index.php`.

## Установка

1. Скопируйте `.env.example` в `.env` и укажите подключение к MySQL.
2. Примените миграции:

   ```bash
   php bin/migrate.php
   ```

   Для своевременной блокировки курсантов настройте запуск `php bin/expire-students.php` по cron, например раз в час. При входе и открытии CRM проверка также выполняется автоматически.

3. Создайте первого директора:

   ```bash
   php bin/create-director.php --login=director --email=director@example.ru
   ```

   Команда покажет одноразовый временный пароль. При первом входе директор обязан его заменить. В существующей установке команда нужна, если директора и заместителя ещё нет.

   Вместо создания нового кабинета можно назначить директором действующего администратора: `php bin/promote-director.php --login=логин`.

4. Для локального запуска:

   ```bash
   php -S 127.0.0.1:8080 index.php
   ```

## Проверка

Проверка синтаксиса и правил доступа:

```bash
find app routes bin tests -name '*.php' -print0 | xargs -0 -n1 php -l
node --check assets/js/app.js
php tests/access_policy.php
```

Проверка срока доступа в подключённой базе выполняется в транзакции с откатом:

```bash
php tests/db_access.php
```

End-to-end smoke test создаёт временного курсанта, проверяет CRUD, блокировку, сброс пароля и чат, а затем удаляет тестовые данные:

```bash
ADMIN_PASSWORD='текущий-пароль-администратора' php tests/http_smoke.php
```

## Структура

- `app/Core` — подключение, маршрутизация, авторизация, CSRF и рендеринг.
- `app/Models` — пользователи, диалоги и сообщения.
- `app/Controllers` — HTTP сценарии первого этапа.
- `app/Views` — серверные шаблоны интерфейса.
- `assets` — адаптивные стили и клиентские взаимодействия.
- `database/migrations` — воспроизводимая схема MySQL.
- `bin` — команды установки.
- `tests` — end-to-end проверка основных сценариев.

## Безопасность

- Пароли хешируются через `password_hash()` и никогда не хранятся в открытом виде.
- Все SQL запросы с пользовательскими данными используют подготовленные выражения PDO.
- Все изменяющие запросы защищены CSRF токеном.
- Заблокированный или удалённый пользователь немедленно теряет доступ.
- Нельзя заблокировать или удалить собственную учётную запись.
- Файл `.env` исключён из Git; реальные реквизиты базы не должны попадать в репозиторий.
