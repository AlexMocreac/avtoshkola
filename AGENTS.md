# Agent instructions

- Preserve Russian and other non-ASCII text as UTF-8. When editing files or running scripts, ensure the shell and tools do not replace Cyrillic characters with question marks or mojibake. Verify changed text after writing it.

- By default, display listed data as read-only information rather than inline editing fields. Show an edit button at the end of each row only to users with permission to edit, and open a modal containing the record and its update options when clicked.
